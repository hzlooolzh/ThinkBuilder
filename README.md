# ThinkBuilder

把一张流程图，变成 AI 能直接照着干活的工程骨架。

ThinkBuilder 是一个画「逻辑结构」的编辑器：你在里面画逻辑块和逻辑线，它把这张图机械地导出成一棵**极省 token、结构清晰**的文件夹树。装了配套工具的 AI（DeepSeek Harness 里的模型）会先读这棵树，弄清「先做什么、每块要什么输入、产出什么、有什么规范」，然后按块实现、逐块打勾。

> 图只描述逻辑，不是真实代码目录。AI 读它，不写它。

## 它解决什么问题

让 AI 写一个完整项目时，真正的成本不是打字，而是**结构丢失**：需求散在对话里，先后顺序靠猜，做完一块不知道下一块要什么。ThinkBuilder 把这些固化成一张图：

```
项目（根块）           ← 与项目标题同名，永远是矩形
├─ 数据层             ← 矩形 = 包含下层
│  ├─ 表结构          ← 三角 = 处理
│  └─ 存储适配        ← 三角 = 处理
├─ 录入
│  ├─ 表单界面
│  ├─ 表单校验        ← 菱形 = 条件判断，O 是出口清单
│  ├─ 保存
│  ├─ 提示校验失败
│  ├─ 清空表单
│  └─ 提示写入失败
└─ 统计
```

每个块有自己的描述块：**标题 / 完成 / 期望输入 / 期望输出 / 处理描述 / 工作规范需求**。

## 安装

在 DeepSeek Harness 的插件市场里搜索 **ThinkBuilder** 安装；或者：

```bash
dsh plugin add github:hzlooolzh/ThinkBuilder#path:/packages/editor-ui
```

装完刷新页面，左侧栏会出现 ThinkBuilder 图标。

## 用起来

1. 点侧栏图标 → 选工作区根目录（可以填任意路径）→ 新建或打开工程。
2. 画：矩形（可包含子块，子块画在它身体里，最多展开两层）、菱形（出口数 = 期望输出项数，菱形内部写出口名）、三角（处理）、圆（起止标记，导出时忽略）。
3. 右键面板里填每块的描述块；拖动连线建立流向；双击矩形进入下一层。
4. 点「导出…」选目标目录，得到：

```
<目标目录>/<项目名>/<项目名>__TBROOT__/
├─ _.tb                     ← 本块的描述 + 内部流向，几行纯文本
├─ 数据层/
│  ├─ _.tb
│  └─ ...
```

编辑中的状态存在项目文件夹的 `.thinkbuilder/project.json`（自动保存），导出的 `__TBROOT__` 树是给 AI 读的只读视图。

## AI 侧

插件自带 6 个工具（无需额外 MCP 服务）：`tb_boot`（读整张图，自带完整读法）、`tb_block`（读一块）、`tb_children`、`tb_find`、`tb_check`、`tb_set_done`（完成打勾，编辑器里显示 ✓）。项目按当前会话的工作目录自动定位。

`_.tb` 格式极简（字段行 + 子块行 + 一行流向表达式）：

```
tb1
D 0
I 用户想要一个记账工具
O 可运行的网页工程
P 先做数据层，再做录入与统计，后两者可并行
R 纯前端，数据只存本地
1 数据层 r
2 录入 r
3 统计 r
S 1>(2,3)
```

`>` 串行、`(a,b)` 并列或按菱形出口分支、`;` 续接、`E` 边表（含回环时降级）。

## 仓库结构

```
packages/core/        解析 / 校验 / 导出 / 视图渲染（编辑器与测试共用）
packages/editor-ui/   DSH 插件：宿主工具 + 侧栏面板（本仓库发布的就是它）
packages/tbfd/        可选的 MCP 版本（同一套工具，给不走宿主的场景）
fixtures/             四套示例工程（线性 / 并列+菱形 / 回环 / 半完成）
scripts/              自检、导出/导入回归、HTTP 路由冒烟
SPEC.md               `_.tb` 格式与导出规则的完整规范
```

## 开发

零依赖，只用 Node 内置模块：

```bash
node scripts/selftest.mjs      # core 单元测试 + 四套 fixture 往返逐字节一致
node scripts/editor-smoke.mjs  # 宿主路由（假 ctx + 本地 http）
node scripts/vendor-core.mjs   # 改完 packages/core 后，同步插件用的 core.mjs
```
